# Thư mục Scripts Kiểm tra

## Mục đích
Chứa các script kiểm tra chất lượng tổng hợp.

## Scripts có sẵn

| Script | Mô tả | Trạng thái |
|--------|--------|------------|
| check-all.sh | Chạy tất cả kiểm tra | Template |
| report.py | Tạo báo cáo tổng hợp | Template |

## Hướng dẫn sử dụng
\`\`\`bash
# Chạy tất cả kiểm tra
./check-all.sh /path/to/project

# Tạo báo cáo
python report.py --output /path/to/report.html
\`\`\`
